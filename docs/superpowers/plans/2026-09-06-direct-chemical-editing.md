# 紙面操作の修正

ユーザーの追加要件: 原子はボタンで選んで頂点へ上書きする。手書きを残す機能は廃止し、すべて構造式に変換する。四角で囲んでまとめて消す。ベンゼン環などの大きさを揃える。

## 実装と検証

- [x] 常設の元素パレット。選んだ元素で頂点をなぞる／クリックすると一原子を置換し、空白では一原子を置く。結合モードへ戻るボタンを用意する。原子価補正と Undo は既存経路を使う。
- [x] 未認識線の永続化をやめる。明確な環・文字・折れ線を優先し、曖昧な線も単結合・原子などの構造要素へ必ず変換する。過去ノートの残存手書きも変換し、Undo で戻せる。
- [x] 「範囲消去」で矩形をドラッグすると内側の原子と接続結合を一括削除する。ドラッグ中の対象を表示し、一回の Undo で戻す。
- [x] 自動整形は全成分で同じ結合長（紙面座標 60）を使用する。既存環、インポート、編集後も適用し、立体情報を維持する。
- [x] ユニット回帰、実ブラウザの筆跡入力・Undo・ズーム操作、ビルド、ユーザーの開いているアプリへの反映。

認識候補が曖昧でも描画を構造要素へ変換する。ユーザーの意図を常に正解できるという意味ではなく、修正は原子ボタン、消去、Undo で行えるようにする。

## 結果

163ユニットテスト、39ブラウザテスト、1オフラインテスト、ビルド成功。追加操作、既存描画、15形式の保存を検証。独立レビュー後、無変更のなぞり直しでUndoが前の編集へ混ざる問題と、範囲消去の立体結合プレビューを修正し再レビュー完了。Codex内ブラウザで元素上書きと更新表示を確認した。
