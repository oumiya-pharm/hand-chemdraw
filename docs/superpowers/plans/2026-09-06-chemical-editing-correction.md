# 自動整形と化学的な編集制約の修正

ユーザーの実画面では、認識された線も結合角と長さが不規則なままで、閉じた輪郭が折れ線や未認識筆跡に残っていた。原子価の検査結果を表示するだけで、編集は確定していた。従来の決まった筆跡によるテストでは、この使用体験を保護できていなかった。

- [x] 認識: 揺れた線、丸みのある輪郭、少し開いた輪郭、複数筆で閉じる環をグラフへ変換する。確定済みの環を勝手に再芳香族化しない。
- [x] 化学制約: 新しい過剰な結合次数を戻す。元素の上書きにより不正となる周囲の多重結合を補正する。既存構造を壊す5本目の単結合を追加しない。
- [x] 表示: Indigo WASMの実レイアウトを編集ごとに自動適用し、均一な結合長と一般的な結合角で表示する。別の分子や未変換筆跡の位置を保つ。
- [x] 統合: 認識・化学補正・表示整形を一つのUndoとして扱う。処理中に次を描いた場合、古い整形結果で上書きしない。
- [x] 受入: 不均一な鎖の整形、輪郭の認識、Cの原子価超過、環のC→O、Undo、素早い連続入力を実ブラウザで確認する。

既存の筆跡の解釈を一意に推定できない場合、分子名や安定性を推測して別の化合物へ置き換えない。この修正では原子価と描画規則を保証する。既存の多分岐単結合を無断で削除することでしか直せない場合は、未解決の原因を表示する。

分担: 幾何・グラフ認識、実WASMレイアウト、純粋な原子価補正を独立した作業にし、制御側で入力と履歴の整合性、実画面を確認する。

実行結果は [修正記録](../../evidence/chemical-editing-correction.md) を参照。
