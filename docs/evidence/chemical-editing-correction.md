# 自動整形と化学的な編集の修正記録

2026-09-06。ユーザーから「ただのお絵描きソフト」「化学構造式に自動で整形しない」「ありえない構造も治されていない」と指摘された実画面を確認して修正した。

## 原因と修正

従来は認識した頂点の座標をほぼそのまま描画し、Indigoを主に化学情報と書き出しに使っていた。原子価のエラーも編集確定後の表示にとどまっていた。これでは形が化学構造式らしく整わず、不正な結合も残る。

現在は次の順序で編集する。

1. 筆跡から原子と結合を認識する。丸み・揺れ・軽い閉じ損じ、別々の線からの環の形成も扱う。
2. `repairValence` で原子価を超える新しい結合を取り消し、必要な多重結合次数を下げる。変更した元素に残る旧元素の水素・同位体指定を解除する。
3. `chemistry.clean` が実Indigo WASMで座標を整形する。原子ID・結合ID・元素・電荷・同位体・水素・結合次数・立体指定は維持する。
4. 結果が現在の文書に対応し、次の筆跡を入力していない場合だけ紙面へ反映する。別の分子の整形済み座標と原筆跡は維持する。

紙面には「自動整形 ON」を表示し、書き出しも整形完了を待つ。既存の未変換筆跡のうち認識できる輪と文字は起動時に再認識する。起動時の筆跡変換はUndoで戻せる。

## 特に保護した操作

| 操作 | 確認した結果 |
|---|---|
| 長さがばらばらなジグザグを一筆で描く | 4原子・3結合を維持し、結合長の最大/最小比が1.02未満、内角120度になる |
| 六角形を一辺ずつ描く | 途中のU字型を直線状の鎖に変えず、6原子・3二重結合のベンゼンとして閉じる |
| ベンゼンの頂点にOを書く | Oの結合次数合計が3から2へ下がり、環を保ってC5H6Oになる |
| 4本結合したCへ5本目を描く | 新しい結合とその新規末端だけを取り消し、既存4本とC5H12を維持する |
| 遅い化学処理中に次を描き、Undoする | 古い整形結果で次の入力を消さず、Undo後に整形が起きてもRedoを維持する |
| 確定待ちの筆跡をEscapeで取り消す | 化学整形が永久に待ち状態にならない |
| ベンゼンの二重結合を全部消し、環を開いて閉じ直す | 編集履歴の `orderEdited` を使い、二重結合を勝手に復活させない |
| 近くにある平行な結合を正確になぞる | 別の結合の次数を増やさない |

半分描いた環が動く問題は、Indigoの通常レイアウトが開鎖に別の配座を選ぶことが原因だった。単結合だけの枝分かれしない炭素鎖には、元の曲がる方向を保ち、Indigoの目標結合長・角度を使う候補を追加した。交差や重なりが不適切な候補は通常レイアウトへ戻す。立体指定や多重結合を持つ構造にはこの候補を適用しない。

## 起動の修正

最初の「動かない」は `index.html` の直接表示と、停止したローカルサーバーを確認した。`start.command` / `npm start` を追加し、起動コマンドが終わった後も配信が続くようにした。すでに自分のアプリが起動していれば再利用し、別アプリが同じポートを使用している場合は終了させず理由を表示する。直接HTMLを開いた場合にも起動案内を表示する。

## 限界

この補正は、指定された原子価と図の配置を対象とする。化合物の安定性・存在可能性・合成可能性を保証しない。既存の単結合の接続関係を削除しないと直せない過剰分岐、未対応元素・電荷は理由を表示する。多様な筆者の認識精度とChemDraw全形式の互換性は引き続き未達である。
