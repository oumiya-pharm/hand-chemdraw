# 結合種類・立体表記・イオンの選択

2026-09-06。結合と原子の選択を紙面上部に常設し、READMEに操作と拡張方法を記載した。

## 変更内容

- 単結合、二重結合、三重結合、手前のくさび、奥の破線くさび、不定の波線をボタンで選択。一回のドラッグで一本を描き、既存の線をなぞるか中央をクリックすると同じ結合を変更する。
- くさびは描き始めが細い端。逆向きになぞると端点の向きを反転する。通常の結合へ戻すと立体指定を解除する。自動認識モードは環や炭素鎖の手書きに引き続き使える。
- N⁺、O⁻のプリセットと、選んだ元素の形式電荷を−15～+15で指定する操作を追加。頂点への上書きで反映し、元の元素・電荷にはUndoで戻せる。
- 元素・電荷変更で不要になった旧水素数指定を解除する。同元素の電荷変更では同位体を保持する。
- 編集途中の非立体中心にくさびを付けた際のIndigoエラーを修正。Sketchの解析・整形・変換だけに `ignore-stereochemistry-errors` を設定し、外部ファイルの読み込みは従来の設定を維持する。描画用の指定と有効な立体中心の配置の両方を保持する。
- READMEに起動、具体的な描画手順、結合方向、イオン選択、保存・出力、制約、機能を拡張するファイルと必要な検証を記載。

## 適用範囲

形式電荷はユーザーが指定する値で、pHなどからイオン化を予測しない。非立体中心のくさびは紙面・ノート・MOL・CDXMLに保持されるが、SMILESやInChIに新しい化学的立体中心は生じない。ChemDrawの全形式・文書機能の互換性は未達であり、READMEと対応表に残作業を記載している。
