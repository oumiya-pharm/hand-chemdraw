# 出力形式と互換性の記録

更新: 2026-09-06。`implemented` はこのアプリから出力できるという意味。ChemDraw実機による文書全体の完全互換を意味しない。

比較対象は[ChemDraw公式機能表（2026年5月）](https://assets.revvitysignals.com/asset/0b9656e8-339d-47ab-9834-6c08beb6abee/Full-Dot-Chart-ChemDraw-Suite-of-Products.pdf)の出力項目。バージョン差を確認する際にはこの一覧へ追加する。元の「全形式」の要求を主要形式だけに読み替えない。

| 形式 | 現状 | 実装／検証と残る仕事 |
|---|---|---|
| SMILES | implemented | Indigo WASM。立体・電荷・同位体の試験。Kekulé表記も有効な出力 |
| MOL V2000 | implemented | バージョンを明示。絶対立体の往復試験 |
| MOL V3000 | implemented | 原子IDからファイル番号へ変換。絶対立体の往復試験 |
| SDF V2000 | implemented | 編集中の構造を1レコードとして保存。塩の非連結成分を保持 |
| SDF V3000 | implemented | 同上。複数の独立レコードを扱う編集UIは未実装 |
| CDXML | implemented | 分子構造を出力・再読込。一般の反応図や装飾の完全保持は未実装 |
| CDX | implemented | バイナリのヘッダーと実WASM再読込。Chromeのオフラインダウンロードも検証 |
| InChI | implemented | 電荷・同位体・絶対立体を試験 |
| InChIKey | implemented | 出力専用。キーから構造への逆変換は行わない |
| SVG | implemented | 紙面と共通の描画モデル。くさび・破線・波線・同位体・水素・電荷を表示 |
| PNG | implemented | ブラウザCanvasによる3倍解像度、透過背景 |
| JPEG | implemented | ブラウザCanvasによる3倍解像度、白背景 |
| GIF / BMP / TIFF | 未実装 | 同じSVG描画をCanvasへ描き、端末内エンコーダーで符号化。各形式の別デコーダーによる画像比較が完了条件 |
| EPS | 未実装 | 描画モデルの線・くさび・文字をPostScriptへ変換。フォント／文字の保持を試験する |
| RXN V2000 / V3000 | 未実装 | 反応物・生成物・試薬の役割を持つ文書モデルとUIが先行条件。対応後Indigoで書き出す |
| RDF V2000 / V3000 | 未実装 | 複数反応・レコード属性の保持が先行条件。反応の順序・mappingの再読込を試験 |
| SKC | 未実装・変換器未選定 | 出力仕様と利用可能な実装を確認し、ブラウザWASMまたは専用writerを評価。読込だけ可能な変換器を出力対応と数えない |
| SLN | 未実装・変換器未選定 | 環閉鎖・クエリ・立体のwriterと外部readerで往復試験。SMILESの拡張子変更で代用しない |
| HELM | 未実装 | モノマー定義・接続位置・環化のモデルを追加してIndigo変換を検証 |
| FASTA peptide / DNA / RNA | 未実装 | 配列モデルを追加。非天然モノマーのnatural analogへの情報損失を表示する |
| 3MF | 未実装 | 3D座標または明示的な平面表示由来の印刷シーン、mesh・単位・素材を実装し、別viewerで検証する |
| OLE | 制約の衝突 | WindowsのOS連携。ブラウザのみという確定要件と両立する方法を確認できていない。CDXダウンロードをOLE対応とは呼ばない |
| CIF | 基準資料では読込項目 | 出力として記載されていないため、全出力の達成数に含めない |
| CML / KET | 追加実装 | Indigoで出力・再読込可能。基準資料外の便利な構造交換形式 |
| te JSON | 追加実装 | このアプリの原子・結合・筆跡・名前・配置を保存。編集IDを保持 |

## 次の互換性作業

1. 分子fixtureをChemDraw実機で開き、構造・配置・くさび・同位体・電荷を比較する。テストしたChemDrawのバージョン・OSを記録する。実機がない間は、この項目を完了としない。
2. 画像用エンコーダーを追加し、別デコーダーで寸法・色・文字欠落を確認する。
3. 反応図と配列を編集モデルへ追加してから、その出力形式を有効にする。中身が表現できない段階で形式選択ボタンだけを作らない。
4. SKC/SLNは仕様・writer・配布条件の根拠を揃え、10種類の既知構造で出力と再読込を実証する。実証できなければ全形式互換のブロッカーとして残す。

## 意図的に拒否している入力

現在の分子モデルに保存できない反応・S-group・原子mapping・alias・query・radical・相対／混合立体・複数SDFレコードは、黙って一部を落として開かない。ファイルの意味を保てない場合はエラーを表示する。今後これらのモデルが追加された時点で制限を解除する。

## 完了の定義

各形式で「対応する要素」「表現できない要素」「失う情報」「外部検証記録」を揃える。全出力形式の完了条件は、上の未実装と制約の衝突が解決されること。現状は分子編集の初版であり、この条件にはまだ達していない。
