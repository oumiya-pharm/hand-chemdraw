# 手書き操作の評価仕様

更新: 2026-09-06。

## 判定すること

認識モデルの導入ではなく「紙・鉛筆・消しゴムの動作で目的の構造へ到達すること」を評価する。文字単体の正解率だけで完成扱いにしない。

| 評価 | 受入目標 | 現状 |
|---|---|---|
| 六角形→ベンゼン | 向き、始点、一筆／複数筆に依存しない | 基本の実マウス操作を試験 |
| 頂点へのN | 原子が増えずIDが維持される | 一筆・遅い三筆を試験 |
| 二重結合の片線消去 | 環の接続を保つ | 三本の消去・追記・分子式を試験 |
| 連続編集 | 無関係な原子・結合・位置が変わらない | 速い別領域の連続描画・即時道具切替を回帰試験 |
| Undo | 人の一操作で戻る | 複数筆のNと消去について試験 |
| ローカル動作 | 外部送信ゼロ、通信断後の編集・出力 | Chrome本番ビルドのオフライン受入試験 |
| 認識待ち時間 | 代表操作でpointerupから表示p95 400ms以下 | 確定待ち280msを採用。筆者評価を含むp95は未計測 |
| 描画追従 | 基準機で60fpsを目標、1000原子で操作可能 | 専用の負荷試験は未実施 |
| 自動確定 | 誤確定1%以下、通常操作の自動確定90%以上を目標 | 人の筆跡データによる評価は未実施 |
| 操作感 | 基本課題を化学ツール選択なしで完成 | 鉛筆／消しゴムと補助選択だけで基本操作を実装 |

数値は製品の目標であり、現実の認識率についての主張ではない。

## データ収集

最初の評価用データは、マウスとトラックパッドの両方を使う6人以上、各20課題、3回ずつを目安とする。本人が明示的に出力した筆跡ファイルだけを使う。アプリから自動送信しない。集まらない場合は人数不足をそのまま報告し、自分で生成した折れ線を人の筆跡数に換算しない。

記録: 匿名筆者ID、入力装置、ブラウザ・OS、原筆跡、操作前グラフ、意図した操作、操作後正解グラフ、所要時間、Undo数、候補選択数。学習・閾値調整・最終評価を筆者単位で分離する。座標に揺れを加えた同一筆跡を別筆者の最終評価へ混ぜない。

## 課題

1. 大小・回転・始点を変えた六角形。閉じる直前で止めてから描き足す。
2. ベンゼンの各頂点にN。1/2/3ストローク、筆間隔80/300/900/1500ms。
3. O/C、N/H、文字と炭素鎖を紛らわしい位置に描く。
4. Nを消してOを書き直す。Nの上に別の元素を上書きする。
5. 二重結合の内側または外側だけを消す。三本とも消して戻す。
6. 単結合・多重結合全体を消して環を開く。独立した原子を消す。
7. 描いた直後に別の場所へ移る、消しゴムへ切り替える、Undoする、保存する。
8. 認識中に文書を開く／閉じる。古い結果が新文書へ混入しないことを確認する。
9. 描画中のpointercancel、画面移動、ズーム、復帰。
10. くさび・同位体・電荷を持つ構造を読み込み、無関係な部分を編集して書き出す。

N以外の各対応文字と炭素鎖を組み合わせ、合計20課題へ展開する。作成した課題と正解グラフはバージョン付きで凍結する。

## 集計と採用判断

- 操作正解率: 意図した編集結果と原子・結合・電荷・立体が一致した割合。無関係な部分の変更も誤りに数える。
- 自動確定誤り率: 自動確定した操作のうち誤りだった割合。保留を増やして数値を良く見せないよう自動確定率と併記する。
- p50/p95待ち時間: 最後のpointerupから確定表示まで。認識内部の計算時間だけを測らない。
- 完成時間・訂正数: 誤認識の修正を含め、課題を終えるまでを測る。
- 95%信頼区間と分母を示す。小規模サンプルの100%を一般的な精度保証にしない。

閾値を上げても自動確定率との両立ができなければ、ローカル分類器へ拡張する。テンプレート照合、小型ONNXの各候補について同じ最終評価データを一度だけ使い、モデルサイズ、CPU時間、メモリも比較する。実測を満たさないモデルを精度優先という名目でクラウドへ逃がさない。
