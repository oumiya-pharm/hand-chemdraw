# te — 手書きの化学ノート

紙に鉛筆で描いて、消しゴムで消す感覚で構造式を編集するブラウザアプリです。

六角形を描くとベンゼン環に整い、上のNボタンを選んで頂点をなぞると原子が置き換わります。結合の種類、手前／奥の立体表記、N⁺やO⁻もボタンで選べます。消しゴムで二重結合の片方を消すと単結合になり、横に線を足すと戻せます。認識、化学処理、保存、出力はこの端末だけで実行します。

描画を確定するたびに結合長・角度を自動整形し、どの環も共通の結合長に揃えます。原子価を超える新しい結合は取り消し、元素の上書きで不正になる多重結合は補正します。整形は入力と同じUndoに含まれ、次の入力やRedoを上書きしません。

## 起動

Node.jsの現行LTSまたはNode 25とnpmを利用します。この環境での検証はNode 25.9.0です。

macOSではフォルダ内の **`start.command` をダブルクリック**してください。必要な準備と本番ビルドを行い、ブラウザを開きます。ターミナルからは次の方法でも起動できます。

```sh
npm ci
npm start
```

`http://127.0.0.1:4173/` を開いてください。ターミナルを閉じてもローカル配信は続きます。`index.html` をファイルとして直接開くとアプリは起動しないため、起動案内を表示します。配信ログは `.te-preview.log` です。

開発時は `npm run dev`。通常の前面プロセスとして配信する場合は以下も使えます。

```sh
npm run build
npm run preview
```

本番版の初回表示時にアプリと化学エンジン約12MBを同じ配信元から保存します。Service Workerのインストール完了後に通信を切れます。実行時の外部API、CDN、テレメトリーはありません。開発サーバーはオフライン配信の対象外です。

## まず一つ描く

1. 上段の **「自動」** を選び、紙面にざっくり六角形を描きます。描き終えるとベンゼン環になり、他の環と同じ大きさに整います。
2. 下段の **「N」** を選び、変えたい頂点を短くなぞります。Nの字形を書く必要はありません。クリックでも置換できます。
3. 正電荷を持たせるなら **「N⁺」** を選び、同じ頂点をなぞります。
4. **「二重結合」** を選んで既存の結合をなぞると、その結合を二重結合へ変更できます。
5. **「書き出す」** からSMILESやSDFなどを保存します。間違えた操作は `Ctrl/Cmd+Z` で戻せます。

## 結合の描き方・変更の仕方

上段で線の種類を選びます。選択中のボタンが緑色になります。

| ボタン | 新しく描くとき | 既存の結合を変更するとき |
|---|---|---|
| 自動 | 六角形はベンゼン、折れ線は炭素鎖として認識 | 横に線を足して多重結合にするなど、筆跡から判断 |
| 単結合 | 一本の単結合を描く | 二重・三重・特殊線を通常の単結合に戻す |
| 二重結合 | 一回のドラッグで二重結合を描く | 指定した結合を二重結合にする |
| 三重結合 | 一回のドラッグで三重結合を描く | 指定した結合を三重結合にする |
| 手前 | 塗りつぶしのくさびを描く | 指定した結合を手前のくさびにする |
| 奥 | 破線くさびを描く | 指定した結合を奥のくさびにする |
| 不定 | 立体配置が不定の波線を描く | 指定した結合を不定の波線にする |

**自動以外では、一回のドラッグが一本の結合になります。** 環や折れ線を手書きで認識させたいときは「自動」または `P` に戻してください。

既存の結合は、その線に沿ってなぞるか、線の中央をクリックして変更します。結合のIDや両端の原子を維持し、同じ場所に重複する結合を追加しません。単・二重・三重を選ぶと、その結合のくさびや波線の指定は解除されます。

原子から外へドラッグすると、選んだ種類の結合で枝を追加できます。別の原子まで描けば、両端を接続します。ボタンを選んだまま続けて描けます。自動認識や元素の上書きへ戻るには、対応するボタンを選び直します。

### 手前・奥とくさびの向き

くさびの **描き始めが細い端、描き終わりが太い端** です。立体中心側から置換基側へ描いてください。既存の線を逆向きになぞると細い端と太い端を入れ替えられます。中央のクリックでは現在の向きを維持します。

立体指定は構造データとして記録し、SMILES・MOL/SDFなどの化学出力にも渡します。立体中心を持たない結合にくさびを描いても、化学的な立体中心が新たに生まれるわけではありません。描き途中のくさびも紙面・ノート・MOL・CDXMLに保持でき、SMILESやInChIでは元の分子として扱います。

## 原子とイオンの選び方

下段からC/N/O/S/P/F/Cl/Br/I/H/B/Siを選び、頂点をなぞるかクリックすると、その原子を置換します。空白に描くと選んだ原子を一つ追加します。

| 操作 | 結果 |
|---|---|
| N⁺を選んで頂点をなぞる | 元素N、形式電荷+1へ置換 |
| O⁻を選んで頂点をなぞる | 元素O、形式電荷−1へ置換 |
| 元素を選び、「電荷」の＋／−を押してから描く | 選んだ元素と電荷で追加・置換 |
| 「中性」を押してから同じ原子をなぞる | 選んだ元素の形式電荷を0へ変更 |
| 通常のNやOなどの元素ボタンを選ぶ | その元素の中性状態を選択 |

電荷欄は **これから描く原子の指定** です。欄を変えるだけでは紙面の原子は変わらず、頂点へ上書きして反映します。カーソルにもN⁺などの指定を表示します。電荷だけを変えたい場合は、同じ元素を選んで上書きしてください。

形式電荷を変更すると、インポート時の古い水素数指定を必要な経路で解除し、新しい状態で化学情報を計算します。同じ元素の電荷変更では同位体指定を保ちます。電荷とくさびは見た目だけの装飾ではなく、保存した構造に含まれます。

電荷の指定範囲は−15～+15ですが、すべての元素・電荷の原子価を自動補正できるわけではありません。pHや溶媒からイオン化状態を予測する機能はありません。指定した形式電荷で編集します。

## 消去・移動・大きさ・Undo

- **消しゴム**：線や原子ラベルをなぞって消します。`E` を押している間だけ消しゴムにもできます。結合している原子のラベルを消すとCに戻ります。
- **二重結合の片線を消す**：小さい消しゴムで追加線だけをなぞると単結合になります。通常の線を丸ごと消したい場合は「範囲消去」も使えます。
- **範囲消去**：四角をドラッグすると、内側の原子と接続する結合をまとめて削除します。消える対象を赤く表示します。逆方向のドラッグも可能です。`Escape` でドラッグを取り消せます。
- **選択**：原子をドラッグして位置を調整します。変更した成分には自動整形が適用されます。選んだ原子の電荷を直接増減する補助ボタンも表示します。
- **大きさ**：環・鎖・インポートした構造は、共通の結合長60（紙面座標）に整います。同じ種類の環は同じ大きさになります。拡大・縮小は紙面の表示倍率を変えます。
- **Undo/Redo**：上書き、結合変更、範囲消去と、その操作に続く自動整形をまとめて一操作として戻します。

描き終えた線は原子・結合・環へ変換し、未変換の手書きとして残しません。曖昧な筆跡にも構造要素を割り当てるため、意図と違う変換はUndoやボタンで修正してください。古いノートに残っていた筆跡も読み込み時に変換します。

### ショートカット

| キー | 操作 |
|---|---|
| P | 自動認識の鉛筆に戻る |
| Eを押している間 | 一時的な消しゴム |
| V | 選択と移動 |
| Space＋ドラッグ | 紙面を移動 |
| Ctrl/Cmd＋Z | 元に戻す |
| Ctrl/Cmd＋Shift＋Z | やり直す |
| Ctrl/Cmd＋S | 構造と配置を含む `.te.json` ノートを保存 |
| Escape | 入力中の線・範囲消去を取り消す |

## 保存・読み込み

紙面はこのブラウザのlocalStorageへ自動保存します。「開く」から化学ファイルやSMILES、`.te.json`を読み込めます。画面下のSMILESを押すとコピーできます。「書き出す」の「ノートを保存」は、このアプリで編集を続けるための形式です。

ブラウザの保存データは1文書です。複数タブで同じノートを変更した場合は自動保存を停止して競合を知らせます。必要なノートはファイルにも保存してください。

## 出力

SMILES、MOL/SDF（V2000/V3000）、CDX、CDXML、InChI、InChIKey、CML、KET、SVG、PNG、JPEG、te JSON。

化学変換はIndigo WASM 1.46.0をWeb Workerで実行します。SVG・画像は紙面の配置を保持します。ChemDrawの全形式互換にはまだ達していません。[対応表と残作業](docs/planning/format-compatibility.md)を参照してください。

## 現在の限界

- 手書き認識は幾何処理と小さい記号テンプレートによる初版です。多数の筆者で認識率を測定していません。
- 自動補正は原子価と描画配置を対象とします。化合物の安定性や合成可能性は判断しません。既存の単結合を削除する以外に解決できない過剰な分岐や、未対応の元素・電荷は原因を表示します。
- 反応式、配列、S-group、mapping、query、radical、相対／混合立体、複数SDFレコードはまだ編集できません。読み込みで情報が落ちる場合は拒否します。
- CDX/CDXMLは分子の往復を試験しています。ChemDraw実機による文書全体の互換性試験は未実施です。
- 初版の自動保存はlocalStorageの1文書です。ブラウザデータ削除で失われるため、必要なノートは `.te.json` でも保存できます。容量不足や別タブ競合では保存停止を表示します。

## うまく動かないとき

| 状態 | 確認すること |
|---|---|
| 六角形を描いても環にならない | 結合の「自動」を選ぶ。単結合などの明示モードは一回のドラッグで一本を描く |
| 原子が変わらず別の原子が増えた | 既存の頂点へ近づけて上書きする。カーソルが近い頂点を囲んで表示する |
| くさびの向きが逆 | 細くしたい端から太くしたい端へなぞり直す |
| 電荷ボタンが使えない | 先にNやOなどの原子を選ぶ |
| 「構造を確認してください」と出る | 通知の原子価や立体指定の理由を確認し、元素・電荷・結合を修正する |
| 起動しない | `index.html`を直接開かず、`npm start`で表示されたHTTP URLを開く |
| 更新したボタンが出ない | 本番ビルド後に一度再読み込みし、同じHTTPアプリのタブを閉じて開き直す。オフライン用キャッシュの更新を適用する |

## 開発と検証

```sh
npm test
npm run build
npm run test:browser
npx playwright test --config playwright.production.config.ts
```

ブラウザ試験はインストール済みGoogle Chromeを使用します。未インストール環境ではPlaywright設定のchannelを外し、`npx playwright install chromium` を実行してください。

### 機能を追加・変更する場所

| 対象 | 主なファイル | 合わせて確認すること |
|---|---|---|
| ボタン、選択状態、履歴 | `src/App.tsx` | 元素・電荷・結合モードの切替とUndo/Redo |
| マウス入力とプレビュー | `src/components/SketchCanvas.tsx` | ドラッグ中の状態、ズーム、キャンセル、整形との競合 |
| 結合種類と既存線の上書き | `src/core/bondEditing.ts` | `BondKind`、`BOND_KINDS`、端点の向き、スナップ、原子価補正 |
| 結合ボタンと描画中の記号 | `src/components/BondGlyph.tsx` | 実際の構造描画との形・向きの一致 |
| 元素・電荷の上書き、範囲消去 | `src/core/directEditing.ts` | 同じ元素の電荷だけの変更、範囲外の原子を残すこと |
| 自動手書き認識 | `src/core/editor.ts`、`geometry.ts`、`recognition.ts` | 複数筆跡、環、既存結合への追記、必須変換 |
| 原子価・旧立体情報の補正 | `src/core/valence.ts` | 明示した電荷、水素、同位体、既存の結合を保護すること |
| 紙面とSVG出力 | `src/core/render.ts` | くさび、破線くさび、波線、原子の電荷表示 |
| 化学変換と自動整形 | `src/chemistry/engine.ts`、`src/useChemicalNormalization.ts` | 実Indigo WASMでの往復、ID・立体情報・共通結合長の維持 |
| 保存形式とデータ検証 | `src/core/types.ts`、`src/storage.ts`、`src/components/ExportDialog.tsx` | 新しいデータを読み書きできること、既存ファイルとの互換性 |

新しい結合種類はボタンだけを増やして完了にはしません。データ型、保存時の検証、紙面描画、化学形式への変換がすべて対応する必要があります。現在の結合次数は1～3、立体指定はup/down/eitherです。配位結合や反応矢印などを追加する際は、編集モデルを拡張し、対応しない出力を明示してください。

編集途中の非立体中心に付けたくさびを扱うため、内部のSketchの解析・整形・変換だけにIndigoの `ignore-stereochemistry-errors` を設定しています。外部ファイルの読み込みは従来の厳格な設定を維持します。オプションの意味は[Indigo公式ドキュメント](https://lifescience.opensource.epam.com/indigo/options/index.html)を参照してください。

`src/core/bondEditing.test.ts` は線の上書き・分岐・向きを、`tests/bond-chemistry.test.ts` は実WASMで形式電荷や立体配置を、`tests/bond-tools.spec.ts` は実ブラウザのボタン操作・Undo・出力を検証します。見た目と構造データの両方を確認してください。
